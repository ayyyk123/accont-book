# 가계부 42차 — 동기화 충돌 방지본

## 이번 수정
- 각 기기가 마지막으로 확인한 Firebase 기준번호와 검증값이 일치할 때만 클라우드 저장을 허용합니다.
- 다른 기기가 먼저 최신자료를 저장했거나, 이전 42차 탭이 클라우드 전체자료를 다시 쓴 흔적이 있으면 자동 덮어쓰기를 중지합니다.
- 화면을 숨기거나 앱을 닫을 때는 로컬 저장만 하고 Firebase 전체자료를 다시 쓰지 않습니다.
- 전체 JSON 백업 복원은 사용자가 명시적으로 선택한 기준자료이므로 기존 클라우드 자료를 안전백업한 뒤 새 기준으로 저장합니다.
- 충돌 시 설정의 `클라우드 자료 다시 비교`에서 이 기기 자료와 클라우드 자료 중 하나를 직접 선택합니다.

## 변경하지 않은 영역
- 가계부 state 데이터 구조와 23개 전체백업 항목
- 투자·예산·통장·카드·고정항목의 기존 저장값
- 전체백업 체크섬 방식
- 통장잔액과 예산 계산

## Firebase에 추가되는 동기화 메타정보
가계부 state 바깥에 기준번호, state 검증값, 저장기기 ID, 기준 갱신시각만 추가됩니다. 전체백업에는 들어가지 않으며 가계부 데이터 구조에는 영향을 주지 않습니다.

## 적용 순서
1. PC와 모바일에서 열려 있는 기존 가계부 탭·앱을 모두 닫습니다.
2. GitHub 저장소에 ZIP의 10개 파일을 전부 덮어씁니다.
3. PC 한 기기에서 새 화면을 연 뒤 42차 전체백업 JSON을 불러옵니다.
4. 상단 자동 동기화 완료를 확인한 뒤 모바일을 엽니다.
