# 가계부 42.8차 — All 필터 초기화 일 선택 해제 수정

## 유지되는 42.7차 기능
- 카드 고정지출 승인 완료 후 오늘 완료내역 표시
- 고정저축별 완료 거래내역 조회
- 목적자금 자동 받을 돈과 금전거래 입금 연결
- 받을 돈·줄 돈 정산 통장내역 삭제 시 연결 처리금액 복원
- 지난달 목적자금 받을 돈의 입금 월 연결 및 누적 원금 표시 수정
- All 탭 `필터 초기화` 버튼

## 42.8차 수정
- `필터 초기화`를 누르면 거래유형, 결제구분, 카드, 통장, 대분류, 소분류, 예산구분, 목적자금/투자 상세, 수령상태, 검색어, 결과표 열 필터를 초기화합니다.
- 상단에서 선택한 월과 All 필터의 조회월·종료월은 그대로 유지합니다.
- All 필터의 조회월·종료월 옆에서 선택한 `일`은 초기화되어 다시 `일 선택` 상태가 됩니다.
- 상단 `mainMonth`의 월/일 선택 상태는 건드리지 않습니다.
- 데이터 저장 구조와 계산 로직은 변경하지 않습니다.

## 적용
GitHub 저장소의 기존 파일을 이 ZIP의 파일로 모두 덮어씁니다. 적용 전 현재 자료를 전체 백업해 두는 것을 권장합니다.
