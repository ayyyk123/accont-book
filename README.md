# 가계부 48.03차 · 카드명세서 체크박스 위치·간격 수정

- 카드명세서의 거래별 체크박스를 각 거래의 `거래 수정` 버튼 바로 왼쪽에 배치했습니다.
- `명세서 대조` 텍스트와 별도 체크박스 줄·진행상황 박스를 제거하고 거래 간격을 이전 수준으로 복구했습니다.
- 카드 결제취소 행은 `취소내역 보기` 버튼 왼쪽에 체크박스가 위치합니다.
- 48.02차에 등록한 거래별 확인 체크 상태는 유지합니다 (`cardStatementItemChecks4802` 키 그대로).
- Firebase 저장·동기화, 금액 계산, 납부완료 파란색, 맑은 고딕과 기존 UI 크기는 변경하지 않았습니다.
- 서비스워커 캐시 버전만 갱신해 이전 화면이 남지 않도록 했습니다.
