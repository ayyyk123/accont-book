# 가계부 48.11차 — 카드 청구할인 수정 후 명세서 체크 유지

- 48.10차 전체 13개 파일을 기준으로 수정했습니다.
- 청구할인 수정 후 카드값 화면을 다시 그릴 때, 체크 저장 당시의 할인 전 금액과 화면에 표시된 할인 후 금액을 잘못 비교하던 문제를 수정했습니다.
- 원래 결제금액, 구매일, 사용처, 청구월 등이 바뀌지 않은 거래의 체크는 유지됩니다.
- 원래 거래를 직접 수정한 경우에는 해당 거래만 다시 명세서 대조 확인이 필요합니다.
- 기존 체크 내역은 삭제하거나 초기화하지 않습니다.
- 카드 금액 계산, 예산, Firebase 저장·동기화 방식은 변경하지 않았습니다.
- 업데이트 전 전체 백업 JSON 저장을 권장합니다.
