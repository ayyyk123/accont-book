# 가계부 42.3차 — 날짜 정렬 버튼 재부착 안정화

## 42.3차 수정 내용
- 42.2차의 통장 조회월 연동과 고정수입·고정지출 알림 기능을 그대로 유지합니다.
- 날짜별 내역 화면이 다시 렌더링되거나 탭·모달이 열릴 때 `⇅ 오래된순 / 최근순` 버튼을 다시 확인하고 빠진 경우 재부착합니다.
- All, 통장 거래내역, 카드 사용·카드값 상세, 목적자금, 투자, 검색 등 기존 날짜 정렬 대상 화면에 같은 정렬 설정을 유지합니다.
- 오래된순은 같은 날짜에서 먼저 입력한 내역부터, 최근순은 같은 날짜에서 나중에 입력한 내역부터 표시합니다.
- 데이터 구조, 잔액 계산, 입력·수정·삭제, 백업 형식, Firebase 동기화 로직은 변경하지 않았습니다.

## 적용
GitHub 저장소의 기존 10개 파일을 이 ZIP의 10개 파일로 모두 덮어씁니다. 백업 JSON을 다시 불러올 필요는 없습니다.
