# 가계부 48.10차 — 이번 달 취소된 고정항목 취소선 표시 보완

- 48.09차 소스를 기준으로 변경했습니다.
- 이번 달 취소된 고정수입·고정지출·고정저축은 항목명·금액·설명줄에 취소선을 표시합니다.
- 같은 달 취소된 고정이체도 항목명·금액·설명줄에 취소선을 표시합니다.
- `취소 해제` 버튼에는 취소선을 표시하지 않습니다.
- 버튼 텍스트에 '이번 달 취소'가 있어도 실제 취소된 항목이 아니면 취소선이 나타나지 않도록 상태 문구를 구분합니다.
- 기존의 여러 단계 화면 다시 그리기 후에도 표시가 유지되게 마지막 DOM 출력에서 보정합니다.
- Firebase 동기화·예산·금액 계산·기존 거래 저장 구조는 변경하지 않았습니다.
- 업데이트 전 전체 백업 JSON 저장을 권장합니다.
