# 가계부 47.96차 · 받을 돈 초과 입금 처리

47.95차 전체 13개 파일 유지.

- 받을 돈에 남은 채권보다 큰 실제 입금액도 입력 가능.
- 초과 입금 부분만 `이번 달 예산에 추가하기` 또는 `추가하지 않기` 선택.
- 채권 원금과 초과 수령액은 각각 별도 장부 항목으로 저장하고 같은 계좌에 합계 1회만 반영.
- 초과액을 예산에 포함하는 경우에만 해당 월 소득·생활비 예산 증가. 월 예산을 직접 설정한 달도 명시적 추가 선택 반영.
- 부분입금 처리 기능 유지. 받음 취소 시 연결 초과 입금액도 함께 원복.
- 47.87차 이후의 Firebase 동기화·최신자료 저장 방식은 그대로 유지.

주의: 입금 처리 전 전체 백업 JSON을 보관하세요. 동일 입금이 이미 일반 소득으로 등록돼 있다면 기존 거래와 중복 입력하지 마세요.
