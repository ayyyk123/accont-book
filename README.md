# 가계부 47.87차 — 최신자료 저장 확인 지연 수정

- `최신자료 저장` 클릭 시 이미 Firebase와 동일한 자료는 다시 쓰지 않고 서버에서 최신 데이터를 1회 확인합니다.
- 실제 변경사항이 있는 경우에만 Firebase transaction 저장 후 서버 데이터를 재조회해 일치 여부를 검증합니다.
- 진행 중인 자동 저장이 있다면 완료를 기다리고 추가 쓰기를 중복 시작하지 않습니다.
- 서버 확인 실패 또는 지연 시 완료로 표시하지 않고 명확한 오류를 안내합니다.
- 이전 Firebase 기준 로딩과 PC·모바일 저장 충돌 방지 로직은 유지합니다.

## 사용 전
- 기존 47.86차가 `클라우드 저장 중`에서 멈췄다면 창을 닫거나 새로고침하기 전 전체 백업 JSON을 먼저 보관하세요.
- Firebase 최신 자료가 다른 기기에도 실제 반영돼 있는지 확인한 후 13개 파일을 교체하세요.
- 서버 확인 속도는 네트워크 상태에 따라 달라질 수 있으며 실제 로그인 계정 대상 검증은 별도입니다.
