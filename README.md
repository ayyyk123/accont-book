# 가계부 47.94차 — 일회성 저축 월 예산 차감 반영

- 이번 달 소득으로 자동 계산한 예산에서 ‘이번 달만 저축’ 입력액을 차감합니다. 예: 소득 11,000,000원, 일회성 저축 7,500,000원, 기타 지출·저축 없으면 남은 생활비 예산 3,500,000원.
- 기존 고정저축 계획(완료 시 실제 금액 반영)은 기존처럼 한 번만 차감합니다. 일회성 저축을 그 계획과 중복 산정하지 않습니다.
- 저축 기록을 수정·삭제·다른 달로 옮기면 월별 예산에 다시 반영합니다.
- 상단 월 예산, 예산 탭, 예산 상세, 이월 내역은 같은 공통 계산값을 사용합니다.
- 통장잔액은 이번 수정으로 바뀌지 않습니다. 같은 통장에 저축을 지정한 금액은 실제 이체가 아니므로 금액을 차감하지 않습니다.
- 카드·통장·예상잔액·자동보충, Firebase 동기화와 ‘최신자료 저장’ 함수에는 변경이 없습니다.
- 직접 설정한 월 예산이 있으면 해당 예산을 기준으로 저축금액을 차감합니다.
