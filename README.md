# 가계부 42.6차 — 목적자금 받을 돈 입금 월 연결 수정

## 유지되는 42.5차 기능
- 카드 고정지출 승인 완료 후 오늘 완료내역 표시
- 고정저축별 완료 거래내역 조회
- 목적자금 자동 받을 돈과 금전거래 입금 연결
- 받을 돈·줄 돈 정산 통장내역 삭제 시 연결 처리금액 복원

## 42.6차 수정
- 지난달 목적자금에서 발생한 받을 돈을 이번 달에 입금 처리해도, 통장 거래일은 실제 입금일로 유지하면서 목적자금 수령 실적은 원래 발생 월에 반영합니다.
- 이 문제로 입금 후에도 받을 돈 잔액이 줄지 않던 현상을 수정했습니다.
- 반복 입금 시 자동 받을 돈의 ‘처음 빌려준 금액’이 커졌던 표시를 현재 실제 총액으로 정상화합니다.
- 42.5차에서 이미 입금 처리된 연결 누락 건은 새 버전 최초 실행 시 자동으로 연결을 복구합니다.

## 적용
GitHub 저장소의 기존 파일을 이 ZIP의 파일로 모두 덮어씁니다. 적용 전 현재 자료를 전체 백업해 두는 것을 권장합니다.
