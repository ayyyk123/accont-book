# 가계부 48.05차 · 거래 등록 반응속도 및 자동저장 확인 개선

- 거래 등록 시 전체 화면을 동기적으로 다시 그리던 병목을 줄여 모달 닫힘을 먼저 반영하도록 조정
- 여러 렌더 요청은 다음 화면 프레임에 한 번으로 통합, 기존 계산 함수는 그대로 실행
- Firebase transaction이 성공하고 현재 상태와 클라우드 기준 상태가 일치할 때만 자동저장 완료 표시 갱신
- 마지막 입력/수정 시각이 저장 확인보다 최신이라 계속 '반영 확인 전'으로 남던 상태 보정
- Firebase 최신본 우선, 동시 수정 충돌 보호, 기존 '최신자료 저장' 수동 확인 유지
- 브라우저와 실제 Firebase 접속 환경에 따라 저장 반응속도는 달라질 수 있음

주의: 자동저장 완료 표시와 '최신자료 저장'의 서버 재조회 확인은 구별됩니다. 실제 계정에서 거래 등록 후 자동저장 완료가 보이는지 먼저 확인하세요.
