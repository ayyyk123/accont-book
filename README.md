# 가계부 42.2차 — 통장 조회월 연동·고정수입/지출 알림

## 42.2차 수정 내용
- 상단 조회월을 바꾸면 `통장별 전체 거래내역`의 시작일과 종료일도 해당 월의 1일~말일로 자동 변경됩니다.
- 통장 카드의 `거래내역` 버튼으로 열 때도 상단에서 선택한 월이 바로 적용됩니다.
- 오늘 날짜가 되었는데 아직 확인하지 않은 월 고정수입·고정지출을 앱 상단에 표시합니다.
- 고정항목 알림에서 `입금 확인`, `납부 확인`, 카드 `승인 확인`을 바로 열 수 있습니다.
- 오늘이 지난 뒤에도 같은 달 안에서 완료하지 않은 항목은 `미확인`으로 계속 표시됩니다.
- 기존 42.1차의 전체 날짜 정렬, 목적자금 상세·Excel 저장, 데이터 구조, 잔액 계산, 백업 형식, Firebase 동기화 로직은 유지했습니다.

## 적용
GitHub 저장소의 기존 10개 파일을 이 ZIP의 10개 파일로 모두 덮어씁니다. 백업 JSON을 다시 불러올 필요는 없습니다.
