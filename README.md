# 가계부 44.9차 — 받을 돈 상세 흐름 · 상단 알림 접기

## 44.9차 수정
- 받을 돈·줄 돈 목록 항목을 누르면 처음 금액, 처리 금액, 남은 금액과 함께 분할 입금·상환 내역을 날짜·통장·금액별로 확인할 수 있습니다.
- 받을 돈이 통장 대여금에서 생겼다면 원래 통장 거래를 함께 보여주고, 카드 대신 결제에서 생겼다면 원 카드 사용내역을 연결해 보여줍니다.
- 목적자금에서 자동 생성된 받을 돈은 목적자금 이름을 표시하며, 이름을 누르면 해당 월·해당 목적자금의 사용내역 전체를 바로 확인할 수 있습니다.
- 상단 이체 알림, 고정수입·지출 알림, 카드값 알림 박스에 전체 접기/펴기를 추가했습니다. 접어도 각 박스 헤더의 건수는 계속 보입니다.
- 44.8 기능은 모두 유지하고, 뒤늦게 44.7차로 되돌아 보이던 버전 표시도 44.9차로 고정했습니다.

# 가계부 44.7차 — 임시계정 · 카드값 통장거래 통합

## 44.7차 수정
- 원인을 바로 찾기 어려운 통장 잔액 차이를 `통장 입금/출금 → 임시계정`으로 보관할 수 있습니다.
- 임시계정은 실제 통장 잔액을 맞추는 용도이며 생활비·소득·전체 통장 자산합계에는 포함하지 않습니다.
- 통장별 전체 거래내역에서 신용카드 카드값은 카드별·실제 출금일·청구월 기준 합계 1건으로 표시합니다.
- 합쳐진 카드값 행을 누르면 구성된 카드 사용처·사용일·금액·할부회차를 펼쳐 볼 수 있습니다.
- 기존 44.4차 데이터 구조와 Firebase 저장 구조는 유지합니다.

# 가계부 44.4차 — 대여금 소비 제외 · All 중복 입력버튼 정리

## 44.4차 수정
- `통장 지출 > 금전거래 > 대여금`은 실제 통장 잔액에서는 빠지고 `받을 돈`에는 그대로 등록되지만, 내 생활비 예산과 소비 합계·소비 통계에서는 제외됩니다.
- 기존에 등록된 대여금도 앱을 불러올 때 자동으로 소비 제외 상태로 보정합니다.
- 대여금 회수는 기존처럼 통장에는 입금되지만 소득에는 포함하지 않는 정산 구조를 유지합니다.
- 대여금 입력 화면의 예산 미리보기에서도 차감액을 0원으로 계산합니다.
- All 탭 `월 총내역` 제목 옆의 `+ 카드 사용 / + 대신 결제 / + 소득 / + 통장 입금 / + 통장 출금 / + 통장 지출 / + 통장 이체` 버튼 묶음을 제거했습니다. 상단 `거래등록`과 모바일 `+ 입력`은 그대로 유지됩니다.
- 예정소득, 카드값, 목적자금, 저축, 투자, 통장잔액, 동기화 구조는 변경하지 않았습니다.

# 가계부 44.2차 — 예정소득 실제소득 확정 타입 고정

## 44.2차 수정
- 예정소득을 실제소득으로 확정한 뒤 `통장 입금(소득 제외)`으로 다시 바뀌는 문제를 수정했습니다.
- 실제소득으로 바꿀 때 과거 `excludeFromIncome` 값을 끌고 오지 않고 `소득`으로 확정되도록 수정했습니다.
- 백업 복원·앱 재실행·클라우드 동기화 과정에서도 `planned_income`과 확정된 `income` 타입을 최종 보정합니다.
- 이미 확정 마커가 남아 있는 항목이 잘못 `deposit`으로 바뀐 경우에는 44.2에서 자동으로 `소득`으로 복구합니다.
- 금액·날짜·통장·예산·카드값 등 거래 데이터 값은 변경하지 않고 거래 타입/소득제외 플래그만 보정합니다.

# 가계부 44.1차 — 예정소득 타입 보존 수정

## 44.1차 수정
- 카드 할인·청구할인 등으로 실제 카드 사용금액보다 상대방에게 받을 금액이 더 큰 경우도 등록할 수 있습니다.
- 카드 사용 입력 화면과 연결된 받을 돈 수정 화면에서 `받을 금액 ≤ 카드 사용금액` 제한만 제거했습니다.
- 카드값은 실제 카드 사용금액 그대로 유지되고, 받을 돈은 입력한 금액 그대로 별도 관리됩니다.
- 기존 카드값·예산·통장잔액·받을 돈 입금 처리·동기화 데이터 구조는 변경하지 않았습니다.
- 앱 표시 버전, manifest, service worker 캐시 버전을 44.1로 통일했습니다.

# 가계부 43.9차 — 예정소득 반영 후 남은 예산 수정

## 43.9차 수정
- All 탭 예산 카드의 예정소득 미리보기를 `소득 반영 후 예산`이 아니라 `소득 반영 후 남은 예산`으로 수정했습니다.
- 계산은 `현재 남은 예산 + 미반영 예정소득`으로 표시합니다. 예: -502,872원 + 170,000원 = -332,872원.
- 월 예산을 직접 설정한 달은 실제소득이 늘어도 예산 기준이 유지되므로 남은 예산도 현재 값 그대로 표시합니다.
- 예정소득 저장, 실제소득 전환, 통장잔액, 카드값, 저축, 이체 등 데이터 로직은 변경하지 않았습니다.
- 앱 표시 버전, manifest, service worker 캐시 버전을 43.9로 통일했습니다.

# 가계부 43.7차 — 예정소득 예산 미리보기

## 43.7차 수정
- All 탭 상단 예산 카드 아래에 선택한 달의 `미반영 예정소득` 합계를 표시합니다.
- 월 예산을 소득 기준으로 자동 계산하는 경우 `소득 반영 후 예산`을 현재 예산 + 미반영 예정소득으로 미리 표시합니다.
- 월 예산을 직접 설정한 달은 실제소득이 들어와도 직접 설정 예산이 유지되므로 `소득 반영 후 예산`도 같은 금액으로 표시하고 `직접 설정 예산 유지` 안내를 붙입니다.
- 일 단위 조회 중에는 선택한 날짜까지 예정된 미반영 소득만 합산합니다.
- 예정소득을 실제소득으로 확정하면 미반영 표시에서 빠지고 기존 실제소득·예산 계산에 정상 반영됩니다.
- 예정소득 저장 구조, 통장잔액, 실제소득, 카드값, 저축, 이체 등 기존 데이터 계산 로직은 변경하지 않았습니다.
- 앱 표시 버전, manifest, service worker 캐시 버전을 43.7로 통일했습니다.

# 가계부 43.6차 — 예정소득 입금 확인

## 43.6차 수정
- 소득 입력 화면에 `예정소득으로 등록` 체크 기능을 추가했습니다.
- 예정소득은 확인 전까지 통장 잔액과 실제 소득 합계에 반영하지 않습니다.
- 예정일이 되면 상단에 `예정소득 입금 확인` 알림을 표시합니다.
- `입금 확인`에서 실제 입금일·통장·금액을 확인한 뒤 실제 소득으로 전환합니다.
- All 탭에 선택 월의 예정소득 관리 목록(수정·삭제)을 표시합니다.

# 가계부 43.5차 — 카드 메모

## 43.5차 수정
- `통장 메모`처럼 카드 등록·수정 화면에도 `카드 메모` 입력란을 추가했습니다.
- 카드목록에서 카드 메모를 함께 확인할 수 있습니다.
- 전체 검색에서 카드 메모 내용으로도 카드를 찾을 수 있습니다.
- 기존 카드에는 메모가 빈 값으로 취급되며, 기존 카드·거래·잔액·카드값 계산 데이터는 변경하지 않습니다.

# 가계부 43.4차 — 저축 누계·이체 상대통장 표시

## 43.4차 수정
- `대출·저축` 탭의 `저축 목록` 금액을 고정저축 설정금액이 아니라 해당 저축의 실제 완료 거래 누계로 표시합니다.
- 저축 목록을 누르면 기존처럼 해당 저축의 완료 거래내역만 조회됩니다.
- 통장 예상내역의 보충 이체·수기 이체 예정·고정저축 예정에 `출금통장 → 입금통장`을 함께 표시합니다.
- 저장 데이터 구조, 잔액 계산, 저축 완료 처리, 이체 완료 처리 로직은 변경하지 않았습니다.
- 앱 표시 버전, manifest, service worker 캐시 버전을 43.4로 맞췄습니다.

# 가계부 43.3차 — 버전 표시·PWA 캐시 충돌 정리

## 43.3차 수정
- 43.2차 기능과 데이터 로직은 그대로 유지합니다.
- 오래된 버전 표시 타이머가 42.x/43.1 문구로 되돌리던 표시 충돌을 정리했습니다.
- HTML, manifest, service worker의 버전 참조를 43.3으로 통일했습니다.
- 온라인 실행 시 메인 HTML은 브라우저 HTTP 캐시를 우회해 최신 파일을 우선 확인하고, 오프라인일 때만 캐시본을 사용합니다.

# 가계부 43.2차 — 카드 명세서 상단표시·알림 건수 통일

## 43.2차 수정
- 카드값에서 카드를 펼치기 전 상단 카드 행에도 `명세서 확인완료` / `명세서 일부 확인` / `명세서 재확인 필요` 상태를 표시합니다.
- 기존 `미확인 금액`은 명세서 미확인이 아니라 아직 `납부 완료` 처리되지 않은 카드값이므로 `납부 미확인 금액`으로 문구를 명확히 했습니다.
- 고정수입·지출 알림의 그룹별 건수 표시를 이체 알림처럼 작은 배지 형태로 통일했습니다.
- 데이터 구조·카드값 계산·명세서 확인 저장·고정항목 처리 로직은 변경하지 않았습니다.

# 가계부 43.1차 — 카드사 명세서 확인완료

## 43.1차 수정
- 카드값 화면에서 카드별·결제월별로 `명세서 확인완료`를 표시할 수 있습니다.
- 확인완료는 카드값 납부 완료와 별개로 저장됩니다.
- 확인완료 후 해당 월 카드값이 수정되면 `명세서 재확인 필요`로 표시됩니다.
- 확인완료 버튼을 다시 누르면 확인 표시를 취소할 수 있습니다.
- 기존 거래·카드값·통장 잔액 계산 로직은 변경하지 않았습니다.

# 가계부 43.0차 — 고정수입·고정지출 알림 접기/펴기

## 43.0차 수정
- 상단 고정수입·고정지출 알림의 `미완료 고정항목` 그룹을 접고 펼칠 수 있습니다.
- `오늘 완료한 고정항목` 그룹도 접고 펼칠 수 있습니다.
- 이체 알림과 비슷하게 `+ / −` 버튼으로 상태를 확인할 수 있습니다.
- 기본 상태는 미완료 그룹 펼침, 오늘 완료 그룹 접힘입니다.
- 가계부 데이터 구조·계산·동기화 로직은 변경하지 않았습니다.

# 가계부 42.9차 — 일 선택 달력 오늘 버튼 추가

## 유지되는 42.8차 기능
- 카드 고정지출 승인 완료 후 오늘 완료내역 표시
- 고정저축별 완료 거래내역 조회
- 목적자금 자동 받을 돈과 금전거래 입금 연결
- 받을 돈·줄 돈 정산 통장내역 삭제 시 연결 처리금액 복원
- 지난달 목적자금 받을 돈의 입금 월 연결 및 누적 원금 표시 수정
- All 탭 `필터 초기화` 버튼
- 필터 초기화 시 상단 선택 월과 All 조회월·종료월은 유지, All에서 선택한 일만 해제

## 42.9차 수정
- 월 옆의 `일 선택` 버튼을 눌렀을 때 뜨는 달력에 `오늘` 버튼을 추가했습니다.
- `오늘`을 누르면 해당 월 입력도 현재 월로 바뀌고 오늘 날짜의 일이 자동 선택됩니다.
- 기존 `월 전체로 보기`와 날짜 직접 선택 기능은 그대로 유지합니다.
- 데이터 저장 구조와 계산 로직은 변경하지 않습니다.

## 적용
GitHub 저장소의 기존 파일을 이 ZIP의 파일로 모두 덮어씁니다.

## 44.4차 수정
- 대여금 거래를 수정 후 저장할 때 생활비 제외 표시가 잠깐 풀리고, 이후 동기화/재로딩에서 다시 붙으면서 남은 예산이 오락가락하던 저장 순서 충돌을 수정했습니다.
- 투자수익 처리 정리 로직이 일반 대여금의 소비 제외 표시를 지우지 않도록 저장 직전에 다시 보정합니다.
- 대여금의 금액·분류·통장·받을 돈 연결 구조는 변경하지 않습니다.


## 44.8차 수정
- 신용카드 결제일 당일 상단에 `오늘 카드값 나가는 날` 알림을 표시합니다.
- 카드별 청구월·결제금액·출금통장을 한눈에 확인할 수 있습니다.
- 미납 상태이면 `납부 확인`으로 바로 카드값 납부 처리 화면을 열 수 있습니다.
- 결제일이 지났는데 납부 확인이 안 된 카드값은 출금 확인 알림이 계속 남습니다.
- 결제일 당일 이미 납부 완료한 카드값도 그날 하루는 완료 상태로 표시됩니다.
- 44.7차의 임시계정, 카드값 통합/세부내역/날짜정렬, 모바일 임시계정 동기화 기능은 그대로 유지합니다.
