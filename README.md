# 가계부 47.90차 · 같은 통장 고정저축 허용

- 고정저축에서 출금통장과 입금통장이 같아도 저장 가능. 통장이 하나만 있어도 등록 가능.
- 신규 고정저축의 입금통장 기본값을 출금통장과 동일하게 설정. 기존 항목 수정 시 기존 값 유지.
- 같은 통장 고정저축은 `recurringSavings`로 예정·완료·누적 기록하며 소비/소득이 아님.
- 같은 통장 저축을 완료해도 통장잔액과 미래 예상잔액이 감소하거나 증가하지 않도록 고정저축 가짜 출금 제거.
- 서로 다른 통장 간 저축은 기존처럼 완료 시 송금·입금 반영.
- 고정저축 완료 화면과 진단 검사에서도 같은 통장을 정상으로 취급.
- 통장 거래내역에 같은 통장 저축 완료가 실제 출금처럼 보이지 않도록 잔액 변동 0원으로 표시.
- 기존 Firebase 저장·동기화 로직, 상품권 최근 저장내용, 카드·예산 로직 변경 없음.

배포 전 전체 백업 JSON 권장. Firebase에 연결한 실계정 통합 테스트는 별도 필요.
