# 가계부 48.02차 · 카드값 명세서 건별 대조 체크 + 납부완료 파란색

- 카드값 탭에서 카드/월을 펼치면 결제내역 각 건마다 `명세서 대조` 체크박스가 표시됩니다.
- 체크 진행상황(확인한 건수/전체 건수)과 체크 초기화 버튼을 제공합니다.
- 체크 상태는 Firebase 가계부 데이터에 함께 저장되고 PC/모바일에 동기화됩니다.
- 결제일·결제처·청구액·할부정보 또는 청구월이 변경되면 이전 체크는 현재 내역의 확인으로 인정되지 않습니다.
- 납부 완료는 파란색으로 강조하고 명세서 확인완료는 기존 초록색을 유지합니다.
- 체크는 납부 완료 처리나 명세서 전체 확인완료 버튼과 별개입니다. 체크/해제는 실제 청구액·예산·통장잔액에 영향을 주지 않습니다.
- 기존 48.01차 맑은 고딕, 작은 글씨, Firebase 최신자료 확인/저장 경로를 유지합니다.
