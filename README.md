# 가계부 47.84차 — 실제 실행 저장 경로 재정리

## 변경사항
- 47.83차에서 새로 작성한 Firebase 동기화/서버 직접조회/동시 수정 충돌검사 함수들이 뒤쪽 구버전 스크립트에 의해 덮이는 문제 수정. 이제 파일의 마지막 스크립트에서 해당 함수들을 최종 연결합니다.
- Firebase 서버 조회 실패 시 캐시를 최신본으로 표시하거나 자동 업로드하지 않습니다.
- 같은 항목에 대한 충돌이 발생하면 저장을 잠그고 경고합니다. 현재 기기 데이터는 JSON 백업 후 확인할 수 있습니다.
- 서로 다른 항목의 변경은 트랜잭션 내 3-way 병합을 수행합니다.
- 페이지 시작 시 필요 없는 '최근 저장내용' 추가 Firebase 조회를 제거했습니다.
- 브라우저 탭, 상단 버전 표시를 47.84차로 변경했습니다.
- 카드취소, 고정이체 이번 달 취소, 받은 돈 중복 정리 등 47.82~47.83 기능 유지.

## 꼭 알아두세요
1. **업데이트 전에** 기존 가계부에서 전체 JSON 백업을 보관하세요.
2. PC와 모바일에서 구버전 가계부를 모두 닫고 두 기기를 47.84차로 업데이트하세요.
3. Firebase 규칙을 건드리지 않는 이번 방식은 **47.84차 앱끼리** 충돌을 막을 수 있으나, 실행 중인 구버전 앱의 외부 직접 쓰기 또는 Firebase 콘솔 수동 변경까지 서버에서 100% 막을 수는 없습니다.
4. 실제 PC·모바일 계정의 네트워크 속도는 환경에 따라 달라집니다. Firebase 최신 데이터 확인을 반드시 거치는 구조라 0초 로딩 보장은 불가능합니다.
5. 서버가 응답하지 않으면 이전 데이터 자동 표시보다 데이터 안전을 우선하여 최신 확인 실패 안내를 표시합니다.

**사용자는 Firebase 설정을 별도로 변경할 필요가 없습니다.**
