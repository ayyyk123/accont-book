# 가계부 48.13차 — 여행경비 간편 정산 · 장부/수령 차액

- 기준: 가계부 48.12차 전체 13개 파일. Firebase 동기화 및 기존 금융 데이터는 보존합니다.
- 목적자금의 이번 달 실제 충전 부분에 장부 잔액 − 해당 월 실제 수령액의 차액을 표시합니다. 이월 목적자금의 경우 장부 잔액은 누계, 실제 수령은 선택 월이라는 점을 표시합니다.
- 목적자금의 '여행 정산' 버튼에서 총 지출은 가계부 거래를 합산합니다. 사용자는 일행에게 돌려받을 금액, 상대방, 내 부담액 처리(목적자금/생활비)를 선택합니다.
- 정산 시 돌려받을 금액은 기존 '받을 돈' 항목 1건에 연결되며, 실제 입금은 '입금 처리'를 통해 통장에 반영합니다. 카드 결제 기록과 청구액 자체는 변경하지 않습니다.
- 여행 정산금액을 개별 카드 대신 결제 금액과 중복 입력하지 못하게 검사합니다. 미처리 자동 목적자금 받을 돈은 중복 생성되지 않도록 정리하고, 이미 입금처리된 기록이 있으면 자동 정리를 차단합니다.
- 생활비 부담 선택 시 개인 월 예산 지출에 순수 부담액만 반영합니다. 목적자금 부담 선택 시 목적자금에 순수 부담액만 남깁니다. 정산월에 정산분을 반영하므로 과거 카드 청구액은 변경하지 않습니다.
- '정산 삭제'는 이미 받은 돈이 없는 경우에만 가능합니다. 기존 여행 사용내역은 변경하지 않습니다.
- 임시계정에 기록되어 있는 이사님 지원금 등은 정산 시 새 통장 거래를 생성하지 않습니다. 목적자금의 시작금액 등을 적절히 사용해 장부 기준액을 설정할 수 있지만 은행 수입을 중복 등록하지 마세요.
- 48.12차 청구할인 자동 체크, 이전 버전의 취소선, 상품권 잔액 수정, 월별 예산 및 Firebase 관련 코드는 보존합니다.
- 배포 전 가계부 '전체 백업' JSON을 저장한 뒤 ZIP 전체 파일을 배포하는 것을 권장합니다.
