# 가계부 42.4차 — 화면 멈춤 제거·날짜 정렬 안정화

## 수정 내용
- 42.3차에서 탭 이름 옆 로딩이 계속 돌고 화면이 멈추던 원인을 제거했습니다.
- 날짜 정렬 버튼 탐색 오류를 수정해 All, 통장 거래내역, 카드 내역, 목적자금, 투자, 검색 등 날짜별 내역 화면에 `⇅ 오래된순 / 최근순` 버튼이 표시됩니다.
- 탭 이동, 월 변경, 상세내역 열기, 재조회 후에만 한 번씩 정렬 버튼을 다시 확인하며 반복 DOM 감시는 사용하지 않습니다.
- 오래된순은 같은 날짜에서 먼저 입력한 내역부터, 최근순은 같은 날짜에서 나중에 입력한 내역부터 표시합니다.
- 42.2차의 통장 조회월 연동과 고정수입·고정지출 알림, 목적자금 상세·Excel 저장을 유지했습니다.
- 저장 데이터 구조, 잔액 계산, 입력·수정·삭제, 백업 형식, Firebase 동기화 로직은 변경하지 않았습니다.

## 적용
GitHub 저장소의 기존 10개 파일을 이 ZIP의 10개 파일로 모두 덮어씁니다. 백업 JSON을 다시 불러올 필요는 없습니다.
