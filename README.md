# 가계부 42.5차 — 요청 기능 4종 추가

## 수정 내용
- 카드 고정지출이 승인 확인 전에는 미완료 알림으로, 승인 확인 후에는 오늘 완료한 고정항목으로 남습니다.
- 고정저축 목록의 항목을 누르면 해당 고정저축의 완료 거래내역만 모아서 볼 수 있습니다.
- 목적자금에서 자동 생성된 받을 돈을 금전거래에서 입금 처리하면 선택한 통장에 한 번 반영되고, 목적자금 실제 수령과 받을 돈 완료가 함께 연결됩니다.
- 받을 돈·줄 돈 입금·상환 처리로 생성된 통장 정산내역을 삭제하면 연결된 처리금액도 함께 되돌릴 수 있습니다. 기존 중복 입금은 통장 거래내역에서 중복 건만 삭제하면 됩니다.
- 기존 저장 데이터 구조와 다른 기능은 그대로 유지하고, 위 기능에 필요한 연결 필드만 추가했습니다.

## 적용
GitHub 저장소의 기존 파일을 이 ZIP의 파일로 모두 덮어씁니다. 백업 JSON을 다시 불러올 필요는 없습니다. 적용 전 현재 자료를 전체 백업해 두는 것을 권장합니다.
