# 가계부 42차 — 한국시간·이체예정 오류수정본

## 수정 내용
- 한국시간 오전 9시 전 앱이 전날로 계산되던 문제를 수정했습니다.
- 당일 고정지출 납부완료가 통장 잔액에 즉시 반영됩니다.
- 이체 예정 당일 상단 알림 건수가 정상 표시됩니다.
- 이체 완료 시 보내는 통장과 받는 통장 잔액에 즉시 반영됩니다.
- 상단 미완료 이체 알림에서 이체 예정 내역을 바로 삭제할 수 있습니다.
- 잘못된 최근 동기화 값은 1970년 날짜 대신 기록 없음으로 표시합니다.
- 기존 동기화 충돌 방지 기능과 전체백업 23개 state 구조는 유지합니다.

## 적용
GitHub 저장소의 기존 10개 파일을 이 ZIP의 10개 파일로 모두 덮어씁니다. 데이터 JSON을 다시 불러올 필요는 없습니다.
