# 가계부 42차 — 버전 표시 정정본

## 41.7차에서 변경한 세 가지
1. PC All 표에서 거래 한 행의 가로선이 칸마다 어긋나지 않도록 표 셀 표시만 수정했습니다.
2. 상단에 Firebase 저장이 실제 성공한 마지막 날짜·시간과 로그인 ID를 표시합니다. 표시시각은 가계부 데이터와 분리된 브라우저 전용 키에만 저장됩니다.
3. 회수 완료된 투자에서 추가 원가 지출 때문에 생긴 잔금은 확정손익에서 이미 차감된 범위만 잔금에 중복 표시하지 않습니다. 기존 투자·회수·지출 저장값은 자동 수정하지 않습니다.

## 변경하지 않은 영역
- state 데이터 구조
- Firebase 문서 데이터 구조와 저장 필드
- 전체백업 state 구성과 체크섬 방식
- 통장 잔액 계산
- 기존 투자 원금·회수금·수익 배분 저장값
- 예산, 목적자금, 고정수입·고정지출, 카드·대출 계산

## 버전 표시 정정
- 정적 제목과 과거 버전 표시 함수에 남아 있던 41.7차 문구를 모두 42차로 통일했습니다.
- 서비스워커 캐시 이름과 요청 버전을 갱신해 기존 41.7차 화면 캐시가 다시 표시되지 않도록 했습니다.
- 가계부 state, Firebase 저장 필드, 계산식, 백업 구조는 추가로 변경하지 않았습니다.
