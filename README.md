# 가계부 41차 — 투자 확정손익·고정항목 실제일 반영
## 38차 All 거래카드 배열 수정
- 날짜·구분·수정·삭제를 첫 줄에 배치
- 카드·통장과 일시불·결제예정 정보를 같은 줄에 배치
- 항목과 금액을 같은 줄에 배치
- `분류·거래처` 선택자 누락을 수정해 카드 하단 빈 공간 제거
- 수정·삭제 버튼 크기를 더 작게 조정



## 37.9차 모바일 배열·검색 수정
- 통장,카드관리 모바일에서 통장별 빠른 입력 버튼을 상단 공용 버튼으로 이동
- 통장 카드에는 거래내역·수정·삭제만 남겨 세로 길이를 줄임
- All 거래카드의 수정·삭제 버튼을 상단으로 올리고 버튼 크기를 축소
- 검색,자산비서의 전체 거래 검색은 검색어 없이 종류만 선택해도 검색 가능


## 카드 대신 결제 예산 처리

카드 대신 결제로 받을 돈을 등록한 경우:

- 카드 사용액과 카드 결제예정액은 실제 카드 결제액 전체로 유지
- 내 예산 또는 목적자금에서는 받을 금액만큼 즉시 제외
- 실제로 입금받기 전이어도 받을 돈으로 약속한 금액은 예산을 사용하지 않은 것으로 계산
- 일부 수령 후에도 이미 받은 금액과 남은 받을 금액은 계속 예산에서 제외
- `받지 않기로 한 금액`은 다시 내 예산 사용액에 포함

예: 카드 결제 100,000원, 받을 돈 40,000원

- 카드값: 100,000원
- 예산 사용액: 60,000원
- 받을 돈: 40,000원

## 기간 바로가기 버튼 삭제

- 일반대출 이자 상환내역의 `올해` 버튼 삭제
- 통장별 전체 거래내역의 `이번 달` 버튼 삭제
- 시작일과 종료일은 기존처럼 직접 선택

## 통장목록 버튼과 모바일 배열

- 각 통장 카드에 잘못 추가된 일반 `이체 예정` 버튼 삭제
- 입금·출금·지출·소득·이체·거래내역·수정·삭제 유지
- 통장 메타정보를 버튼과 별도 줄에 배치
- 은행명과 설명이 한 글자씩 세로로 내려가던 모바일 배열 수정

## 자동 잔액 보충 안내

통장 잔액 예상에서 카드 결제통장에만 제한되던 보충 안내를 모든 통장에 적용했습니다.

- 카카오 마이너스통장 포함
- 예정된 카드값·고정지출·기타 출금 후 잔액이 0원 아래로 내려가는 날짜 감지
- 다른 마이너스통장의 사용 가능 한도가 있으면 기존 `다른 마이너스통장에서 이체 예정` 안내 표시
- 통장 카드에 별도 버튼을 넣지 않고 잔액 예상화면에서 필요한 때만 표시

## 수기 이체 예정 등록

`통장,카드관리 > 통장목록` 상단에 `+ 이체 예정 등록` 버튼을 추가했습니다.

입력 항목:

- 보내는 통장
- 받는 통장
- 이체 예정일
- 이체 금액
- 메모

저장한 이체 예정은:

- 완료 전 실제 잔액에는 반영되지 않음
- 각 통장의 잔액 예상과 미반영 예정항목에 표시
- 예정일 당일 또는 날짜가 지나면 최상단 이체 알림에 표시
- `이체 완료` 처리 시 두 통장 잔액에 반영
- 완료한 날에는 `오늘 완료한 이체`에 계속 표시

## 이체 알림 없음

오늘 미완료 이체와 오늘 완료한 이체가 모두 없어도 최상단 알림 영역을 숨기지 않습니다.

- 제목: `이체 알림 없음`
- 안내: `오늘 예정되거나 오늘 완료한 이체가 없습니다.`
- 건수: `0건`

- 저장·백업 복원·클라우드 데이터 로드 시 생성 거래의 분류를 자동 점검 및 교정

## 38.1차 All 거래카드 추가 배열 수정
- 항목 라벨과 항목명을 같은 줄에 표시
- 카드/통장 옆 결제정보는 짧게 유지
- 돌려받기 완료, 소득 제외, 메모 같은 길어지는 설명은 맨 아랫줄 한 줄로 표시
- 기존 10개 파일 구성 유지

## 38.2차 PC 표·통장 거래내역 수정
- PC All 탭의 날짜·구분·결제수단·항목·분류·금액을 창 너비에 맞춰 한 줄로 정렬
- 구분 배지의 글자가 다음 줄로 넘어가지 않도록 수정
- 수정·삭제 버튼을 가로로 나란히 배치
- 상세 설명 전용 열을 추가해 열 밀림을 방지
- 통장,카드관리의 통장별 전체 거래내역에서 수정 가능한 내역을 눌러 수정 가능
- 기존 10개 파일 구성 유지


## 38.3차 PC 메모 열 보완
- All 탭 PC 표 오른쪽 맨끝에 메모 열 추가
- 모바일에서는 기존처럼 긴 메모를 맨 아랫줄에 표시
- 38.2차의 PC 한 줄 정렬과 통장 거래내역 클릭 수정 기능 유지

## 38.4차 PC 메모 전체 표시
- PC All 표의 메모 열 너비 확대
- 긴 메모는 잘리지 않고 여러 줄로 표시
- 창이 좁으면 표 영역에서 가로 스크롤로 전체 열 확인
- 기존 모바일 배열과 통장 거래내역 클릭 수정 기능 유지

## 38.5차 PC All 표 가로 스크롤 수정
- PC All 표에 항상 보이는 가로 스크롤바를 추가
- 가로 스크롤바와 표 본문의 좌우 이동을 동기화
- 메모 열 폭을 넓혀 긴 메모를 가로 스크롤로 끝까지 확인 가능
- 기존 10개 파일 구성과 모바일 배열 유지

## 38.6차 탭 순서 직접 설정
- 기본 순서에서 통장,카드관리 탭을 All 바로 옆으로 이동
- 백업,설정 탭에 탭 순서 설정 추가
- 위/아래 버튼으로 모바일에서도 직접 순서 변경 가능
- PC에서는 순서 번호를 끌어서 이동 가능
- 변경 순서는 저장되고 PC 상단 탭과 모바일 하단 메뉴에 동시에 적용
- 기본 순서 초기화 및 통장,카드관리 All 옆으로 버튼 제공

## 38.7차 통장 거래내역 삭제 기능
- 통장,카드관리 → 통장별 전체 거래내역에서 행을 누르면 기존처럼 수정
- 수정 가능한 거래 오른쪽에 삭제 버튼 추가
- 삭제 버튼은 행 클릭과 분리되어 수정창이 열리지 않음
- 기존 삭제 확인 및 연결 거래 제한 유지

## 38.8차 투자지출·부분회수
- 등록된 투자에 지출내역 추가: 투자금·카드·통장·현금 선택
- 카드지출은 카드값에, 통장·현금 지출은 해당 잔액에 반영
- 모든 투자지출은 지출수단과 관계없이 총 투자액에 포함
- 부분 회수 시 미회수 원금을 손실로 표시하지 않고 투자잔금으로 표시
- 투자 입금 화면 실제입금액 아래에 회수 전·후 투자잔금 표시
- 투자지출 카드내역은 생활비·소비 통계에서 제외하고 카드 결제예정에는 포함

## 38.9차 거래등록·투자수익 차감
- 우측 상단 버튼을 `거래등록` 하나로 통합
- 거래등록에서 입금·출금·지출·소득·이체 선택
- 통장별 입금·출금·지출·소득·이체 빠른 버튼 제거
- 카드 지출과 통장 지출의 예산 구분에 투자수익·투자별 선택 추가
- 투자수익으로 선택한 지출은 생활비 예산에서 제외되고 해당 투자수익에서 차감
- 투자 현황의 현재 평가금액 요약 제거
- 투자별 투자수익을 잔금 아래, 지출·수정·삭제 버튼 위에 표시
- 현재 평가금액 미입력 시 투자수익 0원 표시

## 39차 지출수단 선택 복구
- 거래등록 → 지출에서 카드 지출·통장/현금 지출·카드 대신 결제 선택
- 카드 지출은 기존 카드 사용 입력창으로 연결
- 통장/현금 지출은 기존 통장 지출 입력창으로 연결
- 투자수익 예산 구분 및 투자수익 차감 기능 유지

## 39.1차 예산 잔액·차감 후 미리보기
- 카드 지출과 통장·현금 지출의 예산 구분 아래에 현재 남은 금액 표시
- 입력한 지출액을 반영한 뒤의 예상 잔액을 실시간 표시
- 내 생활비·각 목적자금·각 투자수익 모두 개별 계산
- 금액·날짜·예산 구분·대신 결제 받을 금액을 바꾸면 즉시 갱신
- 기존 거래 수정 시 원래 금액을 되돌려 계산해 중복 차감 방지

## 39.2차 투자지출 내역·접기펴기 수정
- 등록한 투자지출이 투자지출 내역에 즉시 표시
- 새 투자지출 저장 후 해당 내역을 자동으로 펼쳐 확인 가능
- 투자지출 내역의 접기·펴기가 두 번 실행되어 원래 상태로 돌아오던 오류 수정
- 전체 화면의 접기·펴기 버튼도 한 번만 실행되도록 안정화
- 투자지출 수정·삭제 버튼 및 합계 표시 유지

## 39.3차 투자수익 반영·입력칸 정렬
- 통장 입금에서 투자 수익·손실을 입력하면 해당 투자칸의 투자수익에 즉시 반영
- 현재 평가금액이 없어도 입력한 확정수익은 0원으로 숨기지 않음
- 현재 평가금액이 있으면 확정손익과 평가손익을 합산
- 투자수익으로 사용한 지출은 기존처럼 투자수익에서 차감
- 통장 입금의 투자 종류·투자 거래처 선택칸을 가로로 나란히 정렬

## 39.4차 투자 거래내역·연결계좌
- 투자 목록의 투자건을 누르면 해당 투자의 전체 연결 거래내역 표시
- 투자금 출금·회수 원금·수익·손실·투자지출·투자수익 사용내역 포함
- 거래내역에서 각 거래 수정·삭제 가능
- 통장 등록·수정에 연결계좌 선택 기능 추가
- 카카오뱅크 세이프박스처럼 대표 통장 바로 아래에 연결계좌 표시
- 연결계좌의 잔액과 거래내역은 독립적으로 관리
- 대표 통장 삭제 전 연결계좌 해제 확인

## 39.5차 투자 목록 메모 표시
- 투자 목록 각 투자건의 메모를 시작일 아래 별도 영역에 표시
- PC에서는 잔금·수익·버튼 영역을 피해 왼쪽 메모 공간에 표시
- 모바일에서는 투자 정보 아래 전체 너비로 표시
- 여러 줄 메모와 긴 메모도 줄바꿈하여 표시
- 투자건 클릭 거래내역 기능은 그대로 유지

## 39.6차 투자 메모 위치 조정

## 39.7차 투자 완료일·완료 투자수익
- 투자 상태를 진행 중에서 회수 완료로 변경하면 회수 완료일에 오늘 날짜 자동 입력

- 완료 투자수익은 평가금액이 아니라 확정손익에서 투자수익 사용액을 차감해 계산

## 39.8차 투자 필터·완료일·메모 정렬

- 완료 투자만 보기·수익 모아보기 버튼을 필터 방식으로 교체

- 제목·상단·설정·백업 버전을 모두 39.8차로 통일

## 39.9차 투자 현황·필터·메모·완료일 최종 수정

- 모바일 투자 현황을 금전거래 요약처럼 한 줄씩 가로 배열
- 현재 평가금액 요약 제거 유지
- 투자잔금 금액 바로 아래에 경매·주식·기타 종류별 잔금 표시

- 투자 종류 선택 시 투자건 선택창에 해당 종류의 투자건만 표시
- PC 필터를 종류·투자건·손익·초기화·등록 한 줄로 정렬
- 메모를 시작일 바로 아래 정보 영역에 넣어 빈 공간 제거
- 회수 완료일 저장·복원 오류 수정 및 상태 옆에 표시
- 제목·상단·설정·백업 이름을 모두 39.9차로 통일

## 40차 투자 손익 필터·투자지출 검색

- 투자 종류와 투자건을 전체로 둔 상태에서도 수익·손실·0원 필터 단독 사용 가능
- 투자 목록 검색결과·진행 중·회수 완료·잔금·손익 요약을 화면 가운데 정렬
- 투자지출 내역에 투자건·시작일·종료일 검색 추가
- 진행 중·회수 완료 여부와 상관없이 모든 투자지출 표시
- 회수 완료된 투자건의 투자지출에도 회수 완료 배지 표시
- 투자지출 저장 후 내역 자동 펼침 및 검색 결과 즉시 갱신
- 제목·상단·설정·백업 이름을 모두 40차로 통일

## 40.1차 월말 예산 이월 알림
- 매월 말일에 남은 예산 또는 초과 예산이 있으면 상단 알림 표시
- 전액 이월·이월 안 함·나중에 선택 가능
- 선택하지 않으면 다음 달은 이월 0원으로 계산하고 다음 실행 시 다시 알림
- 남은 예산 이월 시 다음 달 예산에 가산
- 초과 예산 이월 시 다음 달 예산에서 차감
- 이월 안 함 선택 시 다음 달은 자체 예산으로 새로 시작
- 이전 달의 남음·초과 기록은 그대로 유지
- 예산 이월은 통장 잔액에 영향을 주지 않음
- 앱 실행 시 데이터 계산 전 중간 예산값을 숨겨 -3,000만 원 깜빡임 방지
- 제목·상단·설정·백업 이름을 모두 40.1차로 통일

## 40.2차 월별 예산 내역·이월 월 선택
- 예산 탭에 `월별 예산` 메뉴 추가
- 월별로 월초예산·월말잔액·처리상태 표시
- 미처리·이월 안 함·처리 불필요·이월 대상 월 상태 구분
- 각 월을 누르면 기본예산·받은 이월액·생활비·고정저축·월말잔액 확인
- 카드지출·통장지출·고정저축·받은 이월액 세부내역 표시
- 월별 상세화면에서 이월할 월을 직접 선택
- 처리 완료한 월도 이월 대상 월 변경 및 최신 월말잔액으로 재처리 가능
- 처리상태를 다시 미처리로 변경 가능
- 여러 월의 남은 예산 또는 초과액을 같은 월로 이월하면 합산
- 매월 말일 알림에서도 이월할 월 직접 선택
- 제목·상단·설정·백업 이름을 모두 40.2차로 통일

## 40.3차 필터·투자지출 복구·분할 이월
- 투자 목록 손익 필터를 현재 선택값으로 직접 검색하도록 교체
- `손익 0원만`에서 `전체 손익`으로 되돌릴 때 반응하지 않던 오류 수정
- 투자지출 데이터가 누락된 경우 연결된 카드·통장 거래에서 자동 복구
- 회수 완료 투자건의 투자지출도 상태와 무관하게 표시
- Firebase 로그인 상태와 클라우드 자료 확인 전까지 시작화면 유지
- 앱 실행 시 -30,000,000원 중간 예산값이 잠깐 보이는 현상 차단
- 월별 예산 기본 조회를 올해 1월부터 현재 달까지 오름차순으로 변경
- 조회연도 선택 추가
- 한 달의 남은 예산·초과 예산을 여러 달로 나눠 이월 가능
- 일부만 이월하면 남은 금액은 미처리 상태로 유지
- 월별 예산 상세와 월말 알림에서 모두 분할 이월 가능
- 제목·상단·설정·백업 이름을 모두 40.3차로 통일

## 40.4차 투자지출 독립 표시·월별예산 기간 조회
- 투자지출 내역을 투자 현황 접힘 영역 밖의 독립 섹션으로 이동
- 진행 중·회수 완료 투자지출 모두 항상 표시
- 현재 state·브라우저 이전 저장자료·카드·통장 연결기록·구형 투자 객체 배열을 통합 조회
- 투자지출이 존재하지만 검색조건에 맞지 않을 때 안내 표시
- 투자지출 총 건수를 제목 옆에 표시
- 월별 예산 기본화면을 올해 1월부터 12월까지 표시
- 시작월·종료월을 직접 선택해 원하는 기간 조회
- `올해 전체` 버튼으로 현재 연도 1월~12월 즉시 복원
- 제목·상단·설정·백업 이름을 모두 40.4차로 통일

## 40.5차 투자수익 사용내역·연도 빠른조회
- 직접 지출에서 예산 구분을 특정 투자수익으로 선택한 거래를 투자 관련 지출 내역에 표시
- 카드 지출에서 투자수익을 예산 구분으로 선택한 거래도 함께 표시
- 실제 투자원금을 늘리는 투자지출과 투자수익 사용을 배지로 구분
- 투자수익 사용내역은 원래 직접 지출·카드 지출 화면으로 수정·삭제 연결
- 투자수익 사용내역은 투자원금 합계에 중복 반영하지 않음
- 월별 예산 기간검색 옆에 지난해·올해·다음해 버튼 추가
- 각 연도 버튼을 누르면 해당 연도 1월부터 12월까지 즉시 조회
- 제목·상단·설정·백업 이름을 모두 40.5차로 통일

## 40.6차 투자지출 처리방식 선택
- 직접 지출과 카드 지출에서 투자수익을 선택하면 처리방식 필수 선택
- `투자원가에 포함`: 총 투자액 증가·투자수익 감소
- `투자 외 개인소비`: 총 투자액 유지·남은 투자수익에서만 차감
- 두 방식 모두 생활비 예산에서는 차감하지 않음
- 투자원가 지출은 투자수익 사용액에서 다시 차감하지 않아 이중 차감 방지
- 기존 투자수익 지출은 수정 시 기본적으로 투자 외 개인소비로 표시
- 투자 목록의 `지출` 버튼을 `원가 지출`로 변경
- 원가 지출 버튼 아래와 전용 입력창에 총 투자원가 포함 설명 추가
- 직접 지출에서 원가 지출과 개인소비 사이를 자유롭게 변경 가능
- 삭제·처리방식 변경 후 과거 복구자료가 다시 나타나지 않도록 차단
- 제목·상단·설정·백업 이름을 모두 40.6차로 통일

## 40.7차 시작화면 멈춤 수정
- 40.6차의 투자원가 포함·투자 외 개인소비 선택 기능 모두 유지
- 시작화면의 `hidden` 상태가 예산 로딩 CSS에 막히던 충돌 수정
- Firebase 또는 렌더링 오류가 발생해도 시작화면을 반드시 해제
- 최종 렌더링을 try/finally로 감싸 무한 로딩 차단
- 최대 3초 후 앱이 반드시 열리는 안전장치 추가
- 제목·상단·설정·백업 이름을 모두 40.7차로 통일

## 40.8차 클라우드 불러오기 호출오류 수정
- 40.5차에서 생긴 월별 예산 함수의 상호 재귀호출 제거
- `ensureBudgetHistoryRange404 → ensureBudgetHistoryYearButtons405 → ensureBudgetHistoryRange404` 반복 차단
- 클라우드 자료를 받은 뒤 `renderAll()` 실행 시 발생하던 `Maximum call stack size exceeded` 수정
- 40.6차의 투자원가 포함·투자 외 개인소비 선택 기능 유지
- 40.7차의 시작화면 강제 해제 기능 유지
- 전체 렌더링 중복 실행 방지
- 화면 렌더링 오류를 클라우드 데이터 오류로 오해하지 않도록 상태문구 보정
- 제목·상단·설정·백업·캐시 버전을 40.8차로 통일

## 40.9차 투자지출 구분조회
- 최신 기준 파일을 40.9차로 변경
- 투자 관련 지출 검색영역에 `지출 구분` 필터 추가
- `전체 지출`, `원가 추가지출`, `개인소비 지출` 선택조회 가능
- 각 내역에 `원가 추가지출` 또는 `개인소비 지출` 배지 표시
- 검색 결과에서 원가 추가지출 건수·합계와 개인소비 건수·합계를 각각 표시
- 원가 추가지출은 총 투자원가에 포함
- 개인소비 지출은 총 투자원가를 바꾸지 않고 남은 투자수익에서만 차감
- 검색 초기화 시 지출 구분 필터도 함께 초기화
- 40.8차의 월별 예산 재귀호출 수정 유지
- 40.7차의 시작화면 멈춤 방지 유지
- 직접 지출·카드 지출의 투자 처리방식 선택과 이중 차감 방지 유지
- 제목·상단·설정·백업·캐시·manifest 버전을 40.9차로 통일


## 41차 투자 확정손익·고정항목 실제일 반영
- 회수 원금으로 아직 보전되지 않은 원가 추가지출을 확정손익에서 자동 차감
- 현재 평가금액이 있는 진행 중 투자는 평가손익에 이미 반영된 원가를 다시 차감하지 않아 이중 차감 방지
- 고정수입·통장 고정지출 확인 시 실제 입금일·출금일을 거래 날짜로 반영
- 카드 고정지출 확인창에 실제 승인일 입력 추가
- 실제 처리일을 All탭의 날짜와 조회월에 반영
- 확인 취소 시 해당 고정항목의 원래 예정일로 복원
- 완료 후 표시되는 `금액 수정` 버튼을 확인 취소 버튼과 같은 흰색 버튼으로 변경
- 40.9차 투자지출 구분조회, 40.8차 재귀호출 방지, 40.7차 시작화면 해제 기능 유지
- 제목·상단·설정·백업·manifest·서비스워커 캐시를 41차로 변경
