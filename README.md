# 가계부 47.93차 — 자동보충 예상잔액 연동

- 47.92차의 기능과 Firebase 최신 자료 저장·조회 로직은 그대로 유지합니다.
- ‘반영 후 잔액’에서 기존 47.46차가 계산하던 가상 자동보충 금액을 다시 포함합니다(47.76차 최종 타임라인 덮어쓰기 해결).
- 자동보충 기본 송금 통장이 설정되어 있어야 출금통장(-), 받는 통장(+) 양쪽에 같은 날짜로 예측 반영합니다.
- 이미 등록된 자동보충 예정이체와 가상 예상이체를 중복 집계하지 않습니다.
- 송금통장이 미설정이면 출처를 임의로 정하지 않고 기존 예상잔액 방식을 유지합니다. 이 경우 자동보충 필요 안내에서 송금통장을 선택할 수 있습니다.
- 예상 자동보충은 시뮬레이션 결과입니다. 실제 거래를 새로 생성하거나 Firebase에 기록하지 않습니다.
- 일반 카드값·고정지출·고정저축·고정이체의 원래 처리와 Firebase 저장 함수는 변경하지 않습니다.
- 과거월의 예상잔액 계산은 기존 47.92차 로직을 유지합니다.
- 통장별 예상잔액 카드와 상세에서 자동보충 예상 입·출금 구분을 보여줍니다.
