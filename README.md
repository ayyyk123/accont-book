# 가계부 48.07차 — 카드 결제일 변경 입력 순서 및 UI 수정

- 체크박스를 선택해도 새 결제일을 임의로 3일로 바꾸지 않습니다.
- 사용자 본인이 카드대금 결제일을 3일로 선택하면, 그때부터 첫 변경일 2026-12-03 (2026년 11월 기준)을 제안합니다.
- KB 국민카드의 기존 결제일이 18일이고 새 결제일을 3일로 선택한 경우에만 일반 사용기간(전전월 20일~전월 19일) 제안을 적용합니다. 이미 별도로 변경해 둔 사용기간은 덮어쓰지 않습니다.
- 체크박스와 라벨은 나란히 배치되고 긴 문장은 자연스럽게 줄바꿈됩니다.
- 48.06차의 기존 납부 보호·미납 청구월 조정 기능과 Firebase 저장 구조는 변경하지 않았습니다.
- 적용 전 전체 백업 JSON 저장을 권장합니다. 첫 변경 청구기간은 KB국민카드 실제 안내와 대조하세요.
