# 가계부 42.1차 — 날짜정렬·목적자금 상세/엑셀 보완

## 42.1차 수정 내용
- 날짜별 거래내역 화면에 `⇅ 오래된순 / 최근순` 전환 버튼을 적용했습니다.
- All 내역, 통장 월별 내역, 통장별 전체 거래내역, 카드 사용내역 등 날짜가 있는 표에 정렬 버튼이 표시됩니다.
- 목적자금 상세내역, 투자 거래내역, 카드값 상세, 검색 결과 등 날짜형 목록에도 같은 정렬 방식을 적용합니다.
- 오래된순은 같은 날짜 안에서 먼저 입력한 내역부터, 최근순은 나중에 입력한 내역부터 표시합니다.
- 목적자금 항목을 눌러 상세 거래내역을 확인하고 현재 정렬 순서대로 Excel 저장할 수 있습니다.
- 기존 데이터 state 구조, 백업 형식, 잔액 계산, 입력·수정·삭제, Firebase 동기화 로직은 변경하지 않았습니다.

## 적용
GitHub 저장소의 기존 10개 파일을 이 ZIP의 10개 파일로 모두 덮어씁니다. 백업 JSON을 다시 불러올 필요는 없습니다.
