# 가계부 41R 데이터 복구 전용

- 정상 작동했던 41차 화면을 기반으로 합니다.
- 시작 시 자동저장, 자동 클라우드 반영, 삭제를 차단합니다.
- 브라우저 localStorage의 현재 원본, 동기화 안전백업, 복구 전 백업 이력을 읽기 전용으로 검색합니다.
- 필요하면 Firebase 자료도 읽기 전용으로 후보에 추가합니다.
- 투자, 투자지출, 고정항목 실제 입금·출금·승인 정보, deposit/withdrawal/income 유형을 비파괴 병합합니다.
- 추천 복구본을 먼저 미리보고 JSON으로 내려받은 뒤, 명시적으로 선택할 때만 이 기기에 저장합니다.
- 이 기기에 복구본을 저장해도 클라우드에는 자동으로 저장하지 않습니다.
