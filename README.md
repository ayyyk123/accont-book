# 가계부 48.09차 — 상품권 현재 보유금액 수정 오류 개선

- 상품권 수정창은 등록 당시 기본금액이 아닌 거래를 반영한 실제 **현재 잔액**을 표시합니다.
- 수정 후 저장하면 입력한 금액과 최종 잔액이 같아지도록 차액만 잔액 보정에 반영합니다.
- 상품권 수령·사용·금전거래 정산 기록을 삭제하거나 중복 생성하지 않습니다.
- 이전 버전에서 40,000원 수령 후 45,000원을 저장하여 85,000원이 된 상품권도, 수정에서 45,000원을 다시 지정하면 45,000원으로 교정됩니다.
- 수정 시 이름만 변경하면 상품권 잔액을 변경하지 않습니다.
- 잔액 보정값이 음수인 경우도 안전하게 유지해 중복 수령액을 제거할 수 있습니다.
- Firebase 동기화 및 자동/수동 저장의 동작과 예산·카드값 계산 로직은 변경하지 않았습니다.
- 데이터 보호를 위해 업데이트 전 전체 백업 JSON 저장을 권장합니다.
