# 가계부 41.7차 — 정상 운영용

## 핵심 수정
- 투자·통장입금·통장출금 등 확장 데이터 복원이 모두 끝난 뒤 Firebase를 시작하도록 초기화 순서를 수정했습니다.
- 투자목록 자동복구, 고아투자 자동생성, 복구 전용창은 포함하지 않습니다. 투자등록은 사용자가 다시 입력합니다.
- 투자목록 삭제 과정에서 명확한 `투자금 회수` 거래가 직접지출로 바뀐 경우에만 통장입금으로 유형을 바로잡습니다. 투자 원금·평가액·메모는 자동 생성하지 않습니다.
- `데이터 최신 불러오기` 버튼은 제거하고 `최신자료 저장` 버튼만 보조 기능으로 유지합니다.
- 버튼을 누르지 않아도 일반 수정 시 로컬과 Firebase에 자동 저장합니다.
- 앱을 백그라운드로 보내거나 닫을 때 현재 자료를 로컬에 즉시 저장하고 클라우드 저장을 시도합니다.
- 로컬과 클라우드의 수정시각을 비교해 더 최근 자료를 자동 반영합니다.

## 유지 기능
- 다음 달 고정수입·고정지출 자동 생성
- 고정항목 실제 입금일·출금일·승인일과 실제 금액 유지
- 월별 예산, 목적자금, 투자수익 예산 구분
- 카드 할부 예산 차감 방식 선택
- All 다중필터, 모바일 카드 배열, PC 표 배열
- 월 남은예산 2단계 상세내역

## 검증
- 인라인 JavaScript 문법 검사
- 중복 HTML ID 검사
- 투자금 회수 유형 보정 및 예산 제외 검사
- 고정지출 실제 처리값 유지 검사
- 다음 달 고정지출 생성 검사
- 일반 수정 자동 로컬 저장 검사
- All 다중선택 필터 검사
- PC·모바일 All 및 예산 상세창 크기·가로 넘침 검사
