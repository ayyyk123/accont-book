# 가계부 48.12차 — 청구할인 저장 시 거래별 명세서 자동 체크

- 기준: 가계부 48.11차 전체 13개 파일.
- 카드값 상세화면에서 `청구할인` / `청구할인 수정`을 눌러 실제 청구할인을 입력 후 저장하면 **그 거래 1건의 명세서 체크박스가 자동으로 체크**됩니다.
- 기존에 체크한 다른 거래의 대조 상태는 유지합니다.
- 체크를 원하지 않는 거래는 기존 체크박스를 다시 눌러 수동 해제할 수 있습니다.
- 할인 초기화(0원으로 저장)는 자동 체크를 유발하지 않습니다.
- 할인값과 체크 여부는 동일한 기존 saveState/Firebase 동기화 경로에서 저장됩니다. 별도 서버 쓰기 호출은 추가하지 않았습니다.
- 카드값·통장·예산 계산과 Firebase 저장/충돌방지 동작은 변경하지 않았습니다.
- 적용 전에 가계부 전체 백업 JSON을 보관하고, 업데이트 후 `클라우드 반영 확인`을 확인하세요.
